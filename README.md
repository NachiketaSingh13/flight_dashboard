# Flight Booking Dashboard

A simple, modern frontend mock for a flight booking dashboard with sample SQL schema.

## Features

- Static HTML + CSS dashboard
- Responsive UI with sidebar and flight cards
- MySQL schema with sample flight, booking, and user data

## Getting Started

### 1. Open `index.html` in a browser
Make sure `style.css` is in the same folder.

### 2. Test SQL
Run `flight_dashboard.sql` in MySQL using VS Code + SQLTools or MySQL Workbench.

---

Feel free to connect it to a backend (Node.js, Django, or ASP.NET Core) if you want full-stack integration.
